# Migration guides

There are no versioned migration guides yet. t4t is early-stage; breaking changes may land without a formal upgrade path.

When you pull a newer copy of the repository:

- Re-read [Configuration](../../getting-started/configuration.md) if `project.toml` or config keys change.
- Check [CLI Reference](../../user-guide/cli-reference.md) for new or renamed commands.
- Review release notes or commit history on the [GitHub repository](https://github.com/francescomucio/tee-for-transform) if available.

If you need help upgrading a project between versions, open an issue or discussion on the repository.
